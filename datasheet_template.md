## 10. План характеризации и воспроизводимость

**Как выполнить.** ADE L - проверка отдельного testbench и выражений; ADE XL - несколько tests, corners, sweeps, specifications и статистика при наличии лицензий/моделей. В обоих случаях измеряет выбранный simulator; ниже в методике принят Spectre. Сохранить ADE state, netlist, model sections, options, outputs, версии и данные.

| Test ID | Анализ | Параметры / sweep | Представление | Run ID / данные |
|---|---|---|---|---|
| `<TB-01>` | `<dc/ac/noise/tran/stb>` | `<полная сетка>` | `<schematic / extracted>` | `<CSV, waveform, plots>` |

Post-layout: LVS -> Calibre PEX -> корректное подключение extracted view/netlist через config -> проверка pin mapping и operating point -> повтор тестов. Конкретное имя extracted view зависит от настройки Calibre/PDK.

Liberate применяется для нужных цифровому flow Liberty timing/power моделей и согласованных arcs. Он не заменяет аналоговые тесты PSRR, noise, dropout и regulation. Наличие Liberate само по себе не означает наличие Liberate AMS и готового flow для mixed-signal macro.

## 11. Проверки и ограничения signoff

| Проверка | Инструмент / доступность | Что записать |
|---|---|---|
| DRC | Calibre DRC, фактический deck | Исходный результат, run/deck, findings, waiver review |
| LVS | Calibre LVS | MATCH/MISMATCH, run/deck, параметры и допустимые black boxes |
| RC extraction | Calibre PEX | Версия, extraction corner, R/C режим, extracted view/netlist |
| ERC | Только реально доступные deck checks | Какие проверки выполнены и что не покрыто; не предполагать отдельный ERC deck |
| PERC | Deck для процесса отсутствует | `not_run`; причина `deck_not_available`; объём автоматической проверки отсутствует |
| Reliability / ESD / latch-up review | Документы процесса и профильный reviewer | Реальная область рассмотрения, доказательства и незакрытые вопросы |

Отсутствующая PERC проверка не получает PASS. Review не обозначать как выполненный PERC. Waiver сохраняет исходный результат инструмента и фиксирует решение; он не устраняет фактическое нарушение.
